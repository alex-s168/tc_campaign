  (alien, `For operating systems, we want to be able to execute code from the RAM.

To do that, we need to make our programm counter load from any address, instead of just from the program component.

We don't wan't to add a second load port to every RAM, because dual-port memory is expensive.
Instead, we are going to use the same memory bus for instructions as for data.

Replace the counter with the new extended counter (which has an initial value of 0x8000, which is the base address of the program component).

Make your computer do this:
[code]
- Read from the memory bus (at the address of the counter) to get the instruction
- Save that instruction into a register
- set hold input on counter
- Wait one tick
- set reset input on timer
- Perform calculation, load, or store
[/code]

To do that, use the timer component you built earlier.

This will make the processor take 2 ticks per instructions, which is okay for now.
`)]
