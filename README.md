# ETC.A Turing Complete Campaign
THIS ONLY WORKS ON THE `save_breaker` BRANCH!

To get started, download the `all_directories.zip` from the latest release.

Unzip that into the `campaign/` directory of your game folder (NOT the save folder).

You should now have directories like `etca_alu` in your `campaign` directory.

Now, you can just start the game, and in the title screen, press `q`, and type in `load etca_campaign`.
